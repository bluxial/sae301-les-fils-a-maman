Note sur « Mon Compte »

Le cadre « Mon Compte (Desktop) » présente les mêmes articles et le même récapitulatif que le panier. Il ne définit pas encore de formulaire de connexion ou de composants de profil distincts.

Architecture CSS · transfert WordPress

Ordre explicite : theme → lf-reset → lf-fonts → lf-tokens → lf-base → lf-components → lf-utilities → lf-overrides. Les variantes mobiles restent à côté de leurs composants. La présentation du catalogue est isolée dans lf-catalogue et exclue de la feuille WordPress.

Ajouter .lf-system au conteneur de tes composants ; personnaliser les variables et lf-overrides. Dans WordPress, le CSS de Storefront est rangé dans la couche theme, la première : les couches du design system passent donc toujours devant.

Retour en haut ↑

Fichier autonome : CSS organisé en couches @layer, polices et visuels intégrés. Feuille portable : system.css. Les classes lf-* composent la bibliothèque dans un conteneur .lf-system. La page est en HTML et CSS uniquement, sans JavaScript : les états (survol, focus, sélection, menu ouvert) utilisent les comportements natifs du navigateur.
